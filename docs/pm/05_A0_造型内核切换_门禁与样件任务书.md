## 2 为什么必须换内核（判据不是感觉，是算子清单）

`s2_graybox.py` 221 次造型调用中，单轴放样占 60%（`L` 108 / `LZ` 24 / `LX` 1）；
`bmesh` / `boolean` / `bevel` / `solidify` / `subsurf` 在 `s2_graybox.py`、
`hardsurface.py`、`parts_lib.py` 中**出现次数全为 0**。`hardsurface.py` 的 16 个
函数（`rect8 / poly_scale / poly_shift / poly_taper_x / blade8 / hexa / poly_blade /
prism_z / loft_poly / loft_sym / loft_z / loft_x / prof_scale / mirror_prof /
ear_clip / signed_area`）全部是「截面缩放 + 沿单轴放样」。

因此以下四件事在现有内核里**原理上做不出来**，只能用贴片假装：

| 缺失能力 | 现有替代 | 为什么替代不成立 |
|---|---|---|
| 内凹、台阶（真凹陷） | 表面贴更厚的 `ledge` / `framed_LZ` 边框 | 边框是凸出薄片，光照下读作贴纸 |
| 通孔、遮蔽关系 | 用 `INK` / `FRAMED` 深色材质假装洞 | 灰模阶段颜色不出体积，侧视即穿帮 |
| 沿面连续变厚度 | `B()` 刀口只收外缘一层 | 收不到整面，做不出「厚→薄」渐变 |
| 甲片与骨架一体化过渡 | 两件独立零件相邻摆放 | 无共享边界，「两条边碰上」而非「一个结构的分界」 |

结论：**这不是参数没调好，是基元集合缺算子。**换内核是唯一解。

## 3 硬门禁（可自动判定，不接受人工声明）

跑 `blender -b -P blender/a0_sample_validate.py`，任一条失败即非零退出并落 JSON。

| 编号 | 判据 | 阈值 | 为什么这条能替代「三角面数」 |
|---|---|---|---|
| A0-1 | 脚本内 boolean 减法次数 | ≥ 1 件主视觉件有 | 有减法才可能有内凹/通孔 |
| A0-2 | 每对象 boundary_edges（开放边） | = 0（水密） | CSG 失败会留开放边，一眼判假 |
| A0-3 | 每对象 islands（连通壳数） | 记录并断言符合设计 | 空壳/碎壳会突变 |
| A0-4 | **genus（亏格，真通孔数）** | 胸 ≥ 3、肩甲 ≥ 1、上臂 ≥ 1、轴套 ≥ 1 | **通孔数就是亏格，无法用贴片伪造** |
| A0-5 | 壁厚变化 | 同一对象内壁厚极差 ≥ 0.02 m | 证明「变厚度」不是靠倒角装 |
| A0-6 | 骨骼：每顶点权重组数 | 恰好 1 且权重 = 1.0 | 刚体蒙皮规格 |
| A0-7 | 骨骼：18 骨命名子集 | 样件含 chest / shoulder_L / elbow_L | 与 rig_contract 同一命名空间 |
| A0-8 | 关节扫掠不穿插 | shoulder_L 在 −30°/0/+30° 三档，肩甲与胸 bbox 不相交 | 用保守判据，宁可假阳性 |
| A0-9 | 包络 | 样件 bbox 落在 s2 实测对应件包络 +0.05 m 内 | 不许靠放大体积「变丰富」 |

**回归门（只判不许变差，不作为目标）**：W0–W6、斜线能量、等周比、单件三角数、
大平板面积占比。这些仍在 `visual_ruler.py` / `area_ruler.py` 里跑，但不再驱动造型。

## 4 样件范围与依据

取「胸 + 单侧肩甲 + 肩关节 + 上臂上段」，理由是**造型缺口与绑定缺口在同一处**：

| 件 | s2 实测（full 构型，米） | 问题 |
|---|---|---|
| 胸 chest | Y 4.880–6.831，X ±1.171 | 正面是与腰连成一片的大平板 |
| 肩甲 sh_L | Y 5.965–7.055，X 0.800–1.860 | 一整块简单曲面，无铰链、无下方机构 |
| 上臂 arm_L | Y 3.896–6.545，X 1.279–2.066 | — |
| 肩关节（设计） | Y 6.60，X 1.20 | 契约值取自 DIM，未过 PROP |

**关键事实**：肩甲底 5.965 与上臂顶 6.545 之间有 0.58 m 重叠，肩关节整个被罩在
甲片里。于是「肩甲怎么连到躯干」「甲下有没有骨架」「旋转时胸甲会不会穿插」
「肩骨怎么绑」是**同一个问题**——这正是样件必须包含肩关节与上臂上段的原因
（Codex/Kimi 原案只取头+胸+肩甲，会漏掉绑定这一半）。

轴套（外径 0.17，内孔 0.085 **真通孔**，沿 X）+ 连杆 + 止口环。轴套穿过铰链槽，
从外侧可见——满足 P3「可动件的轴必须看得见」。

### 5.4 上臂上段 uarm

空心锥筒：外放样（半宽 0.28→0.24，深 0.24）− 内放样（0.20→0.16）⇒ 壁厚 0.08；
减 1 道液压筒安装通孔（z 5.90–6.20）。顶 6.545 进肩窝，底 5.40 切在肘环。

## 8 明确不做的事

- 不做全机。腿、裙甲、背包、头一律不动，等样件通过再说。
- 不追 Unicorn。参照只用来判「倒角宽窄、面阶高差、遮蔽层次是否到位」。
- 不把倒角/刻线/铆钉当解药。倒角在 CSG 之后、按 0.006–0.012 m 加，只负责收光。
- 不动 `PROP` 与整机包络（4.131 × 7.930 × 2.548）。

### 9.2 关键结论：真通孔可以被客观判定

亏格（`(2·islands − χ)/2`）是本轮唯一无法用贴片伪造的指标。胸的 5 个亏格
= 3 道前壁通孔 + 1 个座舱凹腔 + 1 个肩窝穿透；上臂的 2 个亏格 = 液压筒安装孔
同时贯穿前壁与后壁。**贴一片更厚的边框做不出亏格变化**——这就是「换内核」
与「加细节」的分界线。

### 9.3 造型上仍未解决的（诚实清单）

| 问题 | 现状 | 根因 |
|---|---|---|
| 肩甲仍是八棱面，缺 3° 级渐变 | 4 段扫掠截面，相邻面夹角 15–25° | 截面段数不足；需要 8–12 段 + 每段独立倾斜 |
| 胸正面仍是单一大平面 | 只有 1 道横刻线 + 1 道竖刻线 | 缺「面阶群」：应在主平面上再切 0.015 m 深的分区台阶，把一块大面拆成 3–5 块 |
| 上臂是直锥筒，无屈肌/无护腕 | 4 段等腰梯形 | 缺沿长度的非单调外扩（s2 早就记录「比例层做不出踝收、腓肠肌」，这里同因） |
| 肩甲与胸的关系仍是「盖上」 | 相交面对 120，靠「不增长」判据放行 | 未做真正的嵌合止口；P3 要求分缝落在结构边界，这里边界还没设计 |
| 二级细节层级：minimal | 只有 1 片凸出台阶 + 2 道刻线 | 这是下一步的主工作量，不是收尾动作 |

判断：**方法验证通过，造型只到「可分析的体块」，离 Kimi 期望的 Unicorn 做工还差
两级**（面阶群 / 段数加密）。按任务书 §8，不在此处堆倒角与铆钉充数。

### 9.4 踩到的四个坑（已修，留档）

1. **`BevelModifier.clamp_overlap` 在 5.x 改名 `use_clamp_overlap`** —— 写死会抛异常，
   而异常被 `try/except` 吞掉的表现是「倒角全部静默跳过」，模型看着像没做收光。
   已改为 `hasattr` 双名探测。
2. **抽壳时内外层共面** —— 首末段只内缩 w/zf/zb 不缩 z，做差会留下零厚度顶盖，
   布尔结果非流形。必须首末段 z 也内缩。
3. **盲槽不是通孔** —— 液压筒槽第一版 `d −0.18~0.18`，未越过外表面 ±0.24，
   做出来是盲槽，亏格 0。改 `d −0.30~0.30` 贯穿前后壁后才得 2 个亏格。
4. **`object.bound_box` 取的是求值后包围盒** —— pose 刚复位时 depsgraph 未跟上，
   会把 +30° 摆动峰值算进包络（实测虚高 0.12 m）。包络必须用未变形局部顶点。
5. **侧视从 +X 拍等于没拍** —— 整条上臂正好挡在胸与肩甲前面。侧视须从 −X 拍。

### 9.5 下一轮（A1）的最小改动

按优先级，不加新零件、只改已有件：

1. 胸正面切面阶群：主平面上减 2–3 个 0.015 m 深的分区凹槽，把大面拆成 4 块。
2. 肩甲截面从 4 段加到 9 段，每段独立倾斜 3–5°，消掉八棱面读感。
3. 上臂沿长度加一段外扩（肘上 0.06 m 处最粗），做出屈肌轮廓。
4. 肩甲与胸之间补真实止口：胸侧减出 0.02 m 深的嵌合槽，甲片根部插入。
