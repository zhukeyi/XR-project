# 资产交付规格 · M1 → M2

版本：1.0（2026-11-10）
性质：M1 交给 M2 的验收标准。**不满足即退回，不在引擎里修补。**

## 1 交付物清单

| 文件 | 格式 | 必需 | 说明 |
|---|---|---|---|
| `mecha_793.glb` | glTF 2.0 二进制 | ✅ | 主交付，含节点层级与枢轴 |
| `mecha_793.fbx` | FBX 7.4 | 可选 | 备用通道，供外包工具链 |
| `mecha_793.json` | 自检报告 | ✅ | 包围盒、面数、材质数、枢轴清单 |
| `atlas_*.png` | PNG | ✅ | albedo / normal / metallic-roughness 三图 |
| `mecha_793.vat.png` | RGBAHalf | 阶段 B 补 | 无人机顶点动画，见 §7 |

命名规则：`mecha_<高度整数>.glb`，高度变更时文件名跟着变，禁止复用旧名（防止误用旧资产）。

## 2 坐标与单位（最容易出错的一项）

| 项 | 规定 | 违反后果 |
|---|---|---|
| 单位 | 1 Blender unit = 1 m；Unity 1 unit = 1 m | 整机大 10 倍或小 10 倍 |
| 上方向 | Y-up（导出时转换，Blender 内为 Z-up） | 机体躺倒 |
| 正面朝向 | +Z | 座舱朝后、前进键倒车 |
| 缩放 | 导出 scale = 1.0，**导入时不得二次缩放** | 尺寸链全错，且难以定位 |
| 变换 | 顶点写在世界坐标会失去枢轴语义；必须"局部空间顶点 + 节点 TRS" | 旋转舱门时整块绕原点飞走 |
| 三角化 | 导出前三角化 | 引擎内 NGON 不可控 |

## 3 枢轴命名（18 个，缺一不可）

```
hips          chest         head          backpack
shoulder_L    shoulder_R    elbow_L       elbow_R
hip_L         hip_R         knee_L        knee_R
ankle_L       ankle_R       hatch_hinge_L hatch_hinge_R
```
另有：`SeatAnchor`（眼位，座舱内）、`ChestSocket`（座舱挂载点）。
命名不做本地化、不加前缀后缀、不改大小写——M2 的脚本按字面匹配。

## 4 尺寸断言（导出脚本必须自检并写入 JSON）

| 断言 | 阈值 | 依据 |
|---|---|---|
| 包围盒总高 | 7.930 ± 0.02 m | `线稿转3D_方案与评审.md` §15 |
| 脚底最低点 | y = 0 ± 0.005 m | 站在地面上 |
| 肩宽 / 全高 | 0.561 ± 0.005 | 比例锁定 |
| 深度 / 宽 | 0.625 ± 0.005 | 比例锁定 |
| 枢轴齐全 | 18/18 | §3 |
| 游离物体 | 0 | 曾出现混入默认 `Cube` |

任一项不通过则不交付，输出失败原因到 `.json`。

## 5 面数与材质预算

| 资产 | 三角面 | 材质数 | 贴图 |
|---|---:|---:|---|
| 机体 LOD0 | 8–15 万 | ≤ 8 | 1–2K，ASTC 6×6 |
| 机体 LOD1/LOD2 | 30% / 10% | 共用 | 共用 |
| 座舱内景 | 5–8 万，**不降 LOD** | ≤ 6 | 2K（贴脸看） |
| 无人机单型 | 2–3 万 | ≤ 3 | 512–1K |

材质一律 PBR Metallic/Roughness，禁止在引擎里靠调参救贴图。共享材质与 Trim Sheet 优先于多材质。

## 6 绑定规格（M2 执行，M1 保证可执行）

| 项 | 规格 |
|---|---|
| 绑定方式 | **刚体蒙皮**：每顶点 100% 权重绑单骨 |
| 骨集 | 直接复用 §3 的 18 个枢轴命名 |
| 承载 | 单个 SkinnedMeshRenderer（多材质 → 多 submesh） |
| 软变形白名单 | 仅液压管、线束、安全带、柔性护套 4 项 |
| 禁止 | 形态键、双骨混合、变形骨 |

理由：硬表面一旦加权混合，倒角与面板线在转角处塌陷；刚体绑定既保硬边，又只需一次骨骼矩阵上传。

## 7 无人机 VAT 规格（阶段 B）

| 项 | 规格 |
|---|---|
| 布局 | 宽 = 顶点数，高 = 帧数，RGBAHalf 存 position + normal |
| 预算 | 8k 顶点 × 24 帧 ≈ 1.5 MB/型号 |
| 采样 | 顶点着色器按 `(vertexId, frameId)` 采样，用 `unity_InstanceID` 做相位偏移 |
| 断言 | 同屏 40 架、90 Hz 下 CPU 主线程增量 < 1 ms（**必须真机实测**） |

## 8 交付前自检脚本（伪代码）

```python
assert abs(bbox_height - 7.930) <= 0.02
assert abs(bbox_min_y) <= 0.005
assert abs(shoulder_width / bbox_height - 0.561) <= 0.005
assert abs(depth / width - 0.625) <= 0.005
assert set(required_pivots) <= set(found_pivots)
assert stray_objects == []
assert tri_count <= tri_budget
assert material_count <= 8
write_report("mecha_793.json")
```

## 9 常见退回原因（按历史频次）

1. 导入时被二次缩放（Unity 里 Scale Factor 被改成 0.01 或 100）。
2. 顶点写进世界坐标，枢轴变成装饰。
3. 混入默认物体（`Cube`、`Camera`、`Light`）。
4. 材质数超标，移动端 draw call 爆掉。
5. 用旧文件名覆盖新资产，M2 以为是新版。
