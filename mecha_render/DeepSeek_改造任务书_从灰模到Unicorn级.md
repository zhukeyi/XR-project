## 1 结论先行

**大比例已经达标，不像 Unicorn 的原因不在比例。** 十根横线全部落在参考 ±0.04 H 以内，包络 4.131 × 7.930 × 2.486 m 未超。

真正的差距是三条，按贡献排序：

1. **65.1% 的表面积是「一整块大平板」**（单三角 > 0.05 m²，约 22 × 45 cm），参考只有 **0.2%**。这是「白模感」的直接来源，也是最该先打的一条。
2. **每个零件是「挤出来的」，不是「做出来的」**。单件三角数 **30.8 vs 975.2**，差 31.7 倍。我们的零件全部由「一个截面沿一条轴扫掠」生成，只含两种面：直纹侧面 + 平面端盖；参考的零件自带台阶、凹槽、内凹、通孔、局部柱面。
3. **细节没有层级**。我们只有一级（甲片分块）和三级（铆钉、平行槽），**二级（甲片上的边框、台阶、散热口）几乎为零** —— 而二级才是「复杂度」的观感来源。

一句话：**不是几何不够，是几何的位置不对。我们的总表面积 250.74 m²，比参考的 174.32 m² 还多 44%，但其中三分之二摊在了大平板上。**

## 3 差距的机理诊断（六条，按贡献排序）

### 3.1 平板无边 —— 缺倒角（bevel），这是「塑料感」的物理来源

真实硬表面模型里，**每一条外棱都有 0.005–0.02 m 的小倒角**。它的作用不是造型，是**在棱上产生一条窄高光线**。人眼识别「金属 / 硬表面」，靠的主要是这条线，而不是面数。

我们所有零件的棱都是 90° 锐边，于是无论摆多少甲片，渲染出来都是哑光的白色块。**这一条不改，加任何细节收益都要打对折。**

### 3.2 零件是扫掠体 —— 参数化的结构性天花板

`hardsurface.py` 里 `loft_poly` / `loft_z` / `loft_x` 的共同本质：**一个截面沿一条轴扫掠**。这决定了产物只能有两类面：

- 侧面：对应截面顶点之间的**直纹面**（ruled surface）
- 端盖：平面多边形

因此结构上**做不出**以下四样，而它们在参考里到处都是：

| 参考有 | 我们做不出的原因 |
| --- | --- |
| 甲片上的**台阶 / 边框**（外圈高、内圈低） | 需要同一平面内两层高度，扫掠体只能整体变厚 |
| **内凹面**（散热口、凹槽、舱盖） | 扫掠体的端盖是凸多边形扇形三角化，凹口会自交 |
| **通孔**（腋下、腰侧、裙板间、背包与肩胛间） | 闭合放样天然无孔 |
| **局部柱面 / 球面**（关节套、液压缸、肩部转轴） | 直纹面只能是锥，不能是回转体 |

**所以「再加切削」在原理上走不通**：每一次加细节，都是在一个已定死的扫掠体表面**叠加**，细节与基体之间没有结构关系，于是读作「贴片」。用户此前说「原先像一根萝卜，现在只是增加了更多切削，而不是用新结构代替萝卜」—— 这个判断是对的，而且原因就在这里，不在美术能力。

### 3.3 细节无层级

参考的细节是三级结构：

| 级 | 内容 | 我们有没有 |
| --- | --- | --- |
| 一级 | 甲片分块、裙板、肩甲层次、小腿前后甲 | **有**（262 件） |
| 二级 | **每片甲上的边框、台阶、散热口、舱盖、加强筋** | **几乎没有** |
| 三级 | 铆钉、刻线、警示条、小标识 | 有，但**均布**，且与二级无依附关系 |

三级细节如果没有二级做依托，就会读作「在平板上撒点」。这正是我们目前的状态。

### 3.4 没有负空间

参考的剪影是被**空隙**切碎的：腋下、腰两侧、前裙板之间、小腿后侧、背包与肩胛之间、肘后。我们的剪影是几条直线，因为模型是连续实体，唯一的空隙是脚踝的足弓。

**负空间是「机械感」最廉价也最有效的一条**：一个洞比十条槽更能说明「这里是两个零件」。

### 3.5 明度只有两档

材质 base 色虽然有 8 个，但视觉上只有「白」和「深灰」。参考至少五档（白 / 浅灰 / 中灰 / 深灰 / 黑）外加精神骨架红与警示黄。

**同样的几何，明度分五档，观感复杂度约翻倍。** 这是所有改造里性价比最高的一条，且风险为零（不动几何）。

### 3.6 关节是贴片，不是机构

目前的关节是黑色六边形片。参考的关节有轴、套筒、止口、液压杆、运动让位。**观众判断「这是机器」还是「这是雕像」，主要看关节。**

## 4 给 DeepSeek 的改造任务书

### 4.0 纪律（先于一切技术工作，违反即返工）

1. **包络冻结**：4.131 × 7.930 × 2.486 m，三轴一律不许涨。
2. **比例冻结**：`PROP` 字典不许再改；十根横线差必须保持 ≤ 0.04 H。
3. **原稿墨线必须保留**（项目长期约束）。
4. **禁止在已有扫掠体上「贴片」**。任何新细节必须从该片甲的**轮廓或关节位置导出**，不许手写一组绝对坐标去凑曲面。这是前三次脚部返工的直接教训。
5. **先写尺子，再写产物**。任何一项改动，先给出可复算的指标与目标值，再动几何。
6. **必须自己看图**。改完渲染，用图像确认；不许凭 bbox、三角数、零件数宣称「已改善」。
7. **引用必须可核**。任何「参考是多少」的数字，必须写明来自参考 OBJ 的哪个组、按什么分段量出。

### 4.1 W0 分块边界方向 + 剪影缺口（视觉差距最大，最先做）

**依据**（`visual_ruler.py`，同机位渲染图上量得）：

| 指标 | 我们 | 参考 |
| --- | --- | --- |
| 斜线边缘能量占比（正视） | **21.8%** | **44.8%** |
| 水平 + 竖直能量占比 | **75.5%** | **48.7%** |
| 剪影等周比 | **7.95** | **21.21** |
| 凸实度 | 0.683 | 0.561 |

**目标**：斜线占比 ≥ 38%；等周比 ≥ 14；凸实度 ≤ 0.62。

**做法（关键是「转动已有边界」，不是「加斜线装饰」）**：

1. **胸甲分割线向胸口中心汇聚 15–25°**：左右两片胸甲的公共缝不再是竖直线，而是从锁骨外点指向胸口中心。
2. **裙甲下缘向外张开 20–30°**：三片前裙板的下沿不再水平，形成向下的放射。
3. **小腿甲分割线斜切 20°**，且相邻两片**不平行**（为 V7 汇聚度做准备）。
4. **肩甲下沿改斜**，外上角出一个明确的尖。
5. **剪影开缺口**：裆部 V 口、腋下让位、膝后让位、裙板间张角、踝部出刃。
   **注意：内部开洞对等周比完全无效，缺口必须落在外轮廓上。**

**验收**：`visual_ruler` 的 V3 / V4 落带；凹口深度 ≥ 0.15 H 且每处都能对应真实装配间隙。

**禁止**：用贴斜线、加锯齿的方式刷指标。V3 只统计长度 > 40px 的边缘段，V4 只计入深度 ≥ 0.15 H 的凹口。

### 4.2 W1 倒角系统

**目标**：给所有外棱加 0.012 m 的双面倒角，让棱上出现高光线。

**改哪里**：`tools/hardsurface.py` 新增 `bevel(V, F, w=0.012, cos_max=0.906)`；在 `L()` / `LZ()` / `LX()` 返回前统一调用，按零件局部执行。

**做法**：
- 遍历所有边，取共享该边的两个面的法线夹角；`cos θ < 0.906`（θ > 25°）的边判定为「硬棱」。
- 每条硬棱替换为一条宽 w 的四边形条带：两侧顶点分别沿各自面法线内移 `w · tan(θ/2)`。
- 端点处用法线角平分线方向做斜接（miter），避免条带在角上炸开。
- 凹棱（内角）同样处理，但倒角宽度减半（0.006 m），避免吃掉凹槽。

**验收**：`area_ruler` 的大平板面积占比 **65.1% → ≤ 45%**；四视图上每条主棱都有可辨认的窄亮边。

**风险**：倒角会让包络微涨。**必须在零件局部做，且倒角向内，不外扩** —— 向内倒角不改变 bbox。

### 4.3 W2 明度分档（性价比最高，可与 W1 并行）

**目标**：视觉明度从 2 档升到 5 档 + 2 个强调色。

**改哪里**：`s2_graybox.py` 的材质表与 `ARMOR / ARMOR2 / FRAME / RED` 的使用点。

**分档规则（按结构层级，不许随手）**：

| 档 | 明度 | 用在哪 | 目标面积占比 |
| --- | --- | --- | --- |
| 白 | 0.86 | 外甲主面 | 45–55% |
| 浅灰 | 0.72 | 次级甲、甲片边框 | 20–25% |
| 中灰 | 0.52 | 骨架、内衬、裙板内侧 | 12–18% |
| 深灰 | 0.30 | 关节、轴套、散热口内壁 | 8–12% |
| 黑 | 0.10 | 内腔、通孔深处 | < 5% |
| 红 | — | 精神骨架 / 传感器 | 点缀 |
| 黄 | — | 警示条、锁扣 | 点缀 |

**验收**：五档面积占比全部落表；渲染图上能一眼分出「外甲 / 骨架 / 关节」三层。

### 4.4 W3 二级细节生成器（决定「复杂度」观感）

**目标**：把「一块平板」变成「带边框的凹陷面板 + 散热槽」，并且**从轮廓导出**。

**改哪里**：`hardsurface.py` 新增 `panel_with_frame(poly, inset=0.05, step=0.02)`。

**做法**：
1. 对甲片外轮廓多边形做 **inward offset**（0.05 m），得内轮廓。凸多边形可直接向形心缩放后按边法线修正；非凸用 straight skeleton 或逐边偏移 + 求交。
2. 外轮廓与内轮廓之间生成一圈**台阶框**，框面比主面**低 0.02 m**（凹陷，不是凸起）。
3. 内轮廓填一块面板，作为新的主面。
4. 在内轮廓内，沿甲片长轴切 2–4 条散热长槽：槽宽 0.012 m、槽距 0.05 m、槽深 0.02 m。槽的位置由内轮廓参数化（按长轴 0.3 / 0.5 / 0.7 处），**不写绝对坐标**。

**验收**：二级细节件数 ≥ 一级件数 × 2；最大单块无细节平板面积 < 0.02 m²；大平板面积占比进一步降到 **≤ 35%**。

### 4.5 W4 负空间（六处指定开洞）

**目标**：让剪影被空隙切碎。

**指定位置**：① 腋下（肩甲与胸侧之间）② 腰两侧（胸底与髋之间）③ 前裙板之间（裆部 V 形口）④ 小腿后侧（腓肠肌让位）⑤ 背包与肩胛之间 ⑥ 肘后。

**做法**：优先用**分段放样留缝**，不用布尔差集 —— 布尔会引入非流形与退化面，而我们的工具链对退化面敏感（`Soup` 已修过一次）。

**验收**：正视剪影中空隙面积占比 **≥ 6%**（当前约 1%）。需要新增 `silhouette_void_ruler` 量这个值，不许目测。

### 4.6 W5 关节机构化

**目标**：肩 / 肘 / 髋 / 膝 / 踝五处，每处至少 3 件，且是**机构**不是贴片。

**每处必备**：轴（圆柱）、套筒（带止口）、液压杆（缸筒 + 活塞杆 + 两端球铰）。

**做法**：液压杆两端点必须由**骨架关节位置计算**得出（`pos = joint_a.origin`、`joint_b.origin`），杆长随两端点距离自动确定。禁止手写杆长。

**验收**：每处零件数 ≥ 3；液压杆在**侧视图**可见（此前的教训：液压被后甲与外刀口夹住，只有后 3/4 露一点）。

### 4.7 W6 曲面连续性（可选，放最后）

若要做到 Unicorn 的「肌肉感」，直纹面不够。两条可选路径：

- **A（便宜）**：放样截面数 ×4，截面之间用 B 样条插值，得到 C1 连续的侧面。
- **B（彻底）**：对甲片网格做一级 Catmull–Clark 细分，再做一次倒角。

收益主要体现在 35° 视角的高光连续性。**在 W1–W5 做完之前不要碰这一条。**

## 5 执行顺序

**W0 → W1 → W2 → W3 → W4 → W5 → W6**

- **W0 是观感差距的最大来源**（斜线 21.8% vs 44.8%、等周比 7.95 vs 21.21），先做。
- W1 / W2 改动小、风险低，与 W0 并行或紧随其后，做完即可看到明显变化。
- W3 决定「复杂度」观感，是第二梯队的主力。
- W4 / W5 动结构，可能牵连比例线，必须每步复算 `prop_ruler`。
- W6 最贵，且只对高倍近景有意义。

## 7 诚实的上限说明（两条路线，请用户定夺）

**路线 A：继续参数化（本任务书）。**
做完 W1–W5，能达到的是 **RG / MG 级硬表面模型的密度与材质层次** —— 棱有高光、甲有边框、缝有层级、关节是机构。
**仍然不等于 Unicorn 原设的手工雕塑感。** 后者依赖 subdiv 曲面与人工美术决策（每一条曲线为什么这样弯），不是参数化规则能自动产出的。这不是投入问题，是方法论的边界。

**路线 B：以参考 OBJ 为底做结构改造。**
我们手里有完整 Unicorn 网格（330 586 三角、339 个装配组）。另一条路是**不再从零生成**，而是保留参考的二级 / 三级细节，只做：
- 按我们的十根横线重排各装配组的位置与比例；
- 替换需要差异化的部件（头、胸、背包、肩甲外形）；
- 保留参考的关节机构、甲片边框、散热口、负空间。
