# 纹理流程规格 · 图像模型 → 程序化 PBR 四图

> 定位：M2 材质阶段的输入侧规格。图像模型只负责提供「味道」，程序化层负责保证「可用性」。
> 日期：2026-11-06

---

## 1 设计原则

**图像模型不能直接产出可用贴图。** 它出的图有三个致命问题：

| 问题 | 后果 |
|---|---|
| 非无缝（tileable） | 平铺到 3.4 m 宽的胸甲上会出现明显接缝，且接缝位置随 UV 漂移 |
| 光照已烘焙 | 模型把阴影、高光画进了图里，再叠加我们的逐像素光照会「双重打光」，脏且假 |
| 色彩空间不明 | 可能是 sRGB 编码，也可能带 gamma，直接当 albedo 用会整体偏亮或偏暗 |

所以流程的核心不是「生成」，而是**生成之后的六步净化**。

---

## 2 六个环节

### 环节 1 · 生成（图像模型）

**提示词模板**（固定结构，只换材质名与色相）

```
flat {色相} painted armor panel, seamless texture, orthographic top-down,
uniform diffuse lighting, no shadows, no highlights, no perspective,
matte industrial finish, subtle surface variation only
```

**负面提示词**（必须写全）

```
shadow, highlight, reflection, gradient, vignette, perspective, depth of field,
text, watermark, logo, seam, border, frame, 3d render, dramatic lighting
```

**关键约束**
- 必须明确 `uniform diffuse lighting` / `no shadows` —— 这是避免烘焙光照的唯一手段
- 输出尺寸 1024×1024 起，2K 更好
- 每个基础材质出 4 个候选，人工挑 1 个（这一步不可省，选型靠眼）

**产出**：`raw/{material}_{n}.png` × 4 材质 × 4 候选

### 环节 2 · 净化（去光照）

模型做不到完全均匀。用**低频压制**把残留的光照梯度抹掉：

1. 转 float，提取亮度 L
2. 对 L 做半径 = 图宽/8 的高斯模糊，得到低频 `L_low`
3. 归一化：`L' = L / L_low`，再缩放到原均值
4. 反向乘回 RGB

这一步**同时解决两个问题**：抹掉光照梯度、拉平整体亮度。副作用是纹理对比度略降，用环节 5 的细节增益补回。

### 环节 3 · 无缝化（tileable）

按顺序做三步，前两步必做，第三步视需要：

| 步骤 | 方法 | 作用 |
|---|---|---|
| **a. 边缘融合** | 取四边各 5% 宽度，与对边做 alpha 渐变混合 | 消除硬接缝 |
| **b. 频域对齐** | FFT → 把低频分量的相位强制为周期 → IFFT | 消除大尺度色块错位 |
| **c. 镜像重采样** | 按 2×2 镜像拼接后中心裁切 | 仅当 a+b 仍见接缝时用，会引入对称感 |

**验收**：把图 3×3 平铺，做接缝检测（见环节 6），接缝梯度不超过纹理内部梯度的 1.5 倍。

### 环节 4 · 派生 PBR 通道

从净化后的 albedo 派生其余三张。**全部是启发式，不做逆渲染**。

| 通道 | 派生规则 | 说明 |
|---|---|---|
| **Roughness** | `r = 0.95 - 0.45 · sat(L - 0.6) - 0.25 · edge` | 亮处更光滑（漆面反光），边缘更粗糙（磨损）。再叠加 0.06 幅度噪声打散 |
| **Metallic** | 按材质查表给常量（装甲 0.0 / 骨架 0.85），再乘 `1 - wear_mask` | 装甲是漆面非金属；骨架是金属。磨损处金属裸露要单独处理，M2 简化版先不做 |
| **Normal** | 见环节 5 | |
| **AO**（可选） | 对 albedo 亮度做 `1 - 归一化暗部` | 只在 M2 后期增强用，M2 首版可省 |

### 环节 5 · 法线生成

1. **高度图**：`h = L'`（净化后亮度当高度）——漆面纹理的明暗本身就是微观起伏的间接反映
2. **面板线强化**：对 albedo 做边缘检测（Sobel 幅值），幅值高的地方在高度图上**减去** 2–4 px 深度，强化出凹陷感
3. **求梯度**：`dx = ∂h/∂x`，`dy = ∂h/∂y`（Sobel 算子）
4. **转切线空间法线**：`N = normalize(-dx·s, -dy·s, 1.0)`，`s` 是强度系数（默认 2.0，可按材质调）
5. **编码**：`rgb = N · 0.5 + 0.5`

**关键的强度控制**：`s` 太大会让平面看起来像橘子皮。装甲白 `s=1.4`（漆面平整），骨架灰 `s=3.0`（金属粗粝）。

### 环节 6 · 打包与校验

**图集布局**（2K，四个 1024² 区块）

```
┌──────────┬──────────┐
│ 装甲白    │ 装甲蓝    │
├──────────┼──────────┤
│ 警示红    │ 骨架深灰  │
└──────────┴──────────┘
```

输出四个文件：`atlas_albedo.png` / `atlas_normal.png` / `atlas_rough.png` / `atlas_metal.png`

**校验五项**（自动，`tools/texcheck.py`）

| # | 检查 | 通过线 |
|---|---|---|
| 1 | **接缝** | 3×3 平铺后，接缝处梯度 ≤ 内部梯度 ×1.5 |
| 2 | **亮度均值** | 在目标值 ±8% 内（白 0.90 / 蓝 0.26 / 红 0.32 / 灰 0.24） |
| 3 | **法线合法性** | `length(rgb·2-1)` 的均值 ∈ [0.95, 1.05] |
| 4 | **无纯黑/纯白** | 极值像素占比 < 0.5%（避免贴图上出现死黑死白） |
| 5 | **能量谱** | 径向功率谱符合 1/f^α（α∈[1.2, 2.2]），过平说明是噪声、过陡说明是模糊 |

## 3 降级路径

**图像模型不可用时**（无 API、限流、风格不符），退到纯程序化 `gfx/texgen.py`：

| 层次 | 程序化做法 | 与图像模型的差距 |
|---|---|---|
| 底色 + 噪声 | 柏林噪声 × 3 个八度 | 无「手绘感」，但绝对无缝 |
| 面板线 | 网格线 + 随机断开 | 更规整，反而更像工业件 |
| 磨损 | 边缘距离场 × 噪声 | 可控性强于模型 |
| 编号喷字 | PIL 字体 + 剥落遮罩 | **程序化更强**——模型画不准字 |

**结论**：程序化在「规整、可控、文字」上更强；图像模型在「有机感、真实感」上更强。所以最终形态是**混合**：
- 底色与有机纹理 → 图像模型
- 面板线、编号、警示带、磨损遮罩 → 程序化叠加

这样既能通过校验，又有模型带来的质感。

## 4 与 M2 的接口

```python
# gfx/texgen.py 对外只暴露一个函数
atlas = build_atlas(
    sources={'w': 'raw/white_02.png', 'bl': 'raw/blue_01.png',
             'rd': 'raw/red_03.png', 'gr': 'raw/gray_02.png'},
    fallback=True,        # 源文件缺失时自动走纯程序化
    size=2048,
)
# atlas.albedo / atlas.normal / atlas.rough / atlas.metal  均为 PIL.Image
# atlas.uv_rect(key) → (u0, v0, u1, v1)  图集内区块坐标
```

**M1 不受影响**：M1 着色用的是纯色 `Mat.rgb`，纹理接口先留空。M2 接入时只需在 `shade.py` 里把 `albedo = mat.rgb` 换成 `albedo = tex.sample(uv)`。

## 5 工作量

| 环节 | 工期 | 备注 |
|---|---|---|
| 提示词模板 + 出图筛选 | 0.5 天 | 4 材质 × 4 候选，人工挑 |
| 净化 + 无缝化 | 1 天 | 频域对齐是难点 |
| PBR 派生 + 法线 | 0.5 天 | 公式已定，实现直接 |
| 打包 + 校验 | 0.5 天 | 校验器要写 |
| 纯程序化降级 | 1 天 | 与图像模型路线并行开发 |
| **合计** | **3.5 天** | 含在 M2 的 3–4 天内 |
